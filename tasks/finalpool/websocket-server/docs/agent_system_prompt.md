# Agent System Prompt

## General Requirements
Please complete the implementation for websocket-server in the current directory.

## Functional Requirements

### Core Functionality
- Accept WebSocket connections from clients
- Broadcast messages to connected clients
- Handle connection and disconnection events
- Support room-based message routing
- Implement heartbeat monitoring for stale connections

### Implementation Requirements
- Create a Python implementation with proper error handling
- Include unit tests for core functionality
- Document the API with docstrings
- Ensure thread-safety for concurrent connections
