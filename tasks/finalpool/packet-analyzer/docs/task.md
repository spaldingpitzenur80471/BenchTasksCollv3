# Task: Packet Analyzer

## Overview
Build a network packet analyzer that parses binary capture files and generates analysis reports.

## Requirements
- Parse binary packet capture files
- Support Ethernet, IP, TCP, UDP protocol layers
- Extract packet metadata (timestamps, lengths, checksums)
- Handle corrupted packets gracefully
- Generate statistical analysis reports
- Include unit tests

## Deliverables
- Main analysis module
- Test suite
- Documentation
