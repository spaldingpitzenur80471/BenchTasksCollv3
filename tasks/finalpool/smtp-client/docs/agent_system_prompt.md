# Agent System Prompt

## General Requirements
Please complete the implementation for smtp-client in the current directory.

## Functional Requirements

### Core Functionality
- Connect to SMTP servers with TLS support
- Send emails with attachments and HTML bodies
- Handle authentication and errors
- Support connection pooling and retries
- Parse and validate email addresses

### Implementation Requirements
- Create a Python implementation with proper error handling
- Include unit tests for core functionality
- Document the API with docstrings
- Ensure thread-safety for concurrent sending
