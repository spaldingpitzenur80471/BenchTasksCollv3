# Agent System Prompt

## General Requirements
Please complete the implementation for url-shortener in the current directory.

## Functional Requirements

### Core Functionality
- Generate short URLs for long URLs
- Store mappings in a persistent store
- Redirect short URLs to originals
- Support custom aliases
- Track click statistics

### Implementation Requirements
- Create a Python implementation with proper error handling
- Include unit tests for core functionality
- Document the API with docstrings
- Ensure thread-safety for concurrent operations
