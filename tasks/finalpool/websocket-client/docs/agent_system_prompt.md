# Agent System Prompt

## General Requirements
Please complete the implementation for websocket-client in the current directory.

## Functional Requirements

### Core Functionality
- Establish WebSocket connections with TLS support
- Send and receive text and binary messages
- Handle connection lifecycle events
- Implement automatic reconnection logic
- Support heartbeat/ping-pong keepalive

### Implementation Requirements
- Create a Python implementation with proper error handling
- Include unit tests for core functionality
- Document the API with docstrings
- Ensure thread-safety for concurrent messaging
