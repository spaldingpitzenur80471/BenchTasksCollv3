# Task: Regex Engine

## Overview
Build a regular expression engine supporting matching, search and capture groups.

## Requirements
- Implement regular expression matching from scratch
- Support character classes, quantifiers, and anchors
- Handle capture groups and backreferences
- Provide a compile/match/search API
- Optimize pattern compilation for reuse
- Include unit tests

## Deliverables
- Main engine module
- Test suite
- Documentation
