# Agent System Prompt

## General Requirements
Please complete the implementation for utility-scripts in the current directory.

## Functional Requirements

### Core Functionality
- Provide reusable command-line utility scripts
- Support file operations, text processing, and data conversion
- Include help text and usage examples for each script
- Handle edge cases and invalid inputs gracefully
- Support script composition via stdin/stdout

### Implementation Requirements
- Create a Python implementation with proper error handling
- Include unit tests for core functionality
- Document the API with docstrings
- Ensure thread-safety for concurrent execution
