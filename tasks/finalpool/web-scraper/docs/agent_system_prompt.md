# Agent System Prompt

## General Requirements
Please complete the implementation for web-scraper in the current directory.

## Functional Requirements

### Core Functionality
- Fetch web pages with configurable headers
- Parse HTML and extract structured data
- Follow pagination and crawl limits
- Respect robots.txt and rate limits
- Export scraped data to multiple formats

### Implementation Requirements
- Create a Python implementation with proper error handling
- Include unit tests for core functionality
- Document the API with docstrings
- Ensure thread-safety for concurrent scraping
