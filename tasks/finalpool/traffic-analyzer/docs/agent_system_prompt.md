# Agent System Prompt

## General Requirements
Please complete the implementation for traffic-analyzer in the current directory.

## Functional Requirements

### Core Functionality
- Capture and analyze network packets in real time
- Filter traffic by protocol, port, or host
- Aggregate statistics over time windows
- Export analysis results to reports
- Support pcap file input and output

### Implementation Requirements
- Create a Python implementation with proper error handling
- Include unit tests for core functionality
- Document the API with docstrings
- Ensure thread-safety for concurrent analysis
